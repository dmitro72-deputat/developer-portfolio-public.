Project

DocuMind Smart Vision

An iOS document-scanning and organization project built with Swift and SwiftUI.

Prepared for Mac and iPhone acceptance

Implemented features

  • Multi-page document scanning and local text recognition with Apple Vision.
  • A local library with folders, a PDFKit viewer, and PDF/DOCX import.
  • Manual label capture with Smart Scan 360° and matching against a local allergen profile.

Technical services

  • Text and structured data cleanup.
  • CSV and JSON validation.
  • Text document template automation.
  • Small browser-based tools.
